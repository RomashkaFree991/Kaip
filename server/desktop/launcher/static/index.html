Программы

Добавить программу

Поддерживаются .exe, .msi, .deb, .AppImage. По ссылке сервер скачивает файл сам, а не через телефон, так быстрее.

Задачи

Общая папка телефона и сервера

На сервере это ~/Телефон, в Windows-программах — диск P:. Загружай сюда файлы с телефона и скачивай результаты обратно.

Запущено

Разрешение экрана

На телефоне удобнее 1280×720 и горизонтальная ориентация. Чем меньше разрешение, тем быстрее картинка.
