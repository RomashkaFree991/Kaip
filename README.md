# Kaip — программы для ПК на Android-телефоне

Программы (`.exe`, `.msi`, `.deb`, `.AppImage`) работают **на твоём Linux-сервере**, а телефон показывает их экран и управляет ими пальцем.
Файлы с телефона попадают в программы через общую папку, а результаты скачиваются обратно в память телефона.

```
 Телефон (приложение Kaip / браузер)          Сервер (Docker)
 ┌───────────────────────────┐   HTTPS   ┌────────────────────────────────────────┐
 │ Программы │ Экран │ Файлы │ ────────► │ Caddy (HTTPS + вход по паролю)         │
 └───────────────────────────┘           │  ├─ панель Kaip (список, установка)    │
   выбор файла из памяти ───► загрузка   │  └─ noVNC ─► виртуальный экран Xvnc    │
   «Загрузки/Kaip»  ◄─── скачивание      │       Wine (.exe/.msi), .deb, AppImage │
                                         │  /data/shared = «Телефон» = диск P:    │
                                         └────────────────────────────────────────┘
```

## 1. Установка на сервер (один раз)

Нужен Linux-сервер (Ubuntu 22.04+/Debian 12) с открытыми портами 80 и 443. Подключись к нему по SSH и выполни:

```bash
git clone -b ccr-7c177f4b-foguz1 https://github.com/RomashkaFree991/Kaip.git
cd Kaip/server
sudo bash install.sh
```

Скрипт сам:
- поставит Docker;
- создаст файл подкачки, если оперативной памяти меньше 3.5 ГБ (на дешёвых серверах это обязательно);
- спросит пароль и выберет адрес вида `https://1-2-3-4.sslip.io` (это твой IP, HTTPS-сертификат выдаётся бесплатно и автоматически);
- соберёт и запустит всё. Первый раз сборка идёт 5–15 минут.

В конце скрипт покажет адрес. Открой его на телефоне.

## 2. Приложение на телефон

**Вариант А — APK.** Скачай `Kaip.apk` со страницы
[Releases → android-latest](https://github.com/RomashkaFree991/Kaip/releases/tag/android-latest),
установи (Android попросит разрешить установку из браузера), при первом запуске введи адрес сервера.

Что даёт приложение по сравнению с браузером:
- на вкладке «Экран» телефон сам поворачивается горизонтально, скрываются системные панели и экран не гаснет;
- кнопка «Назад» работает как в обычном приложении;
- файлы с сервера сохраняются в **Загрузки/Kaip**;
- адрес сервера можно поменять: «Сервер» → «Сменить сервер».

**Вариант Б — без APK.** Открой адрес в Chrome → меню ⋮ → «Добавить на главный экран». Работает почти так же.

## 3. Как пользоваться

| Вкладка | Что делает |
|---|---|
| **Программы** | «Выбрать файл с телефона» или вставить ссылку на установщик (сервер скачает его сам, это быстрее). Затем «Запустить». |
| **Экран** | Рабочий стол сервера. Тап = клик. Слева у края есть панель noVNC: клавиатура, буфер обмена, полноэкранный режим. |
| **Файлы** | Общая папка: загружай файлы с телефона и скачивай результаты обратно. |
| **Сервер** | Память, диск, процессор, запущенные программы (можно закрыть), разрешение экрана. |

Откуда программы видят файлы телефона:
- Windows-программы (через Wine) — диск **P:**;
- Linux-программы — папка **~/Телефон**.

### Типы файлов

- **.exe**: если это портативная программа, она просто запускается. Если установщик, запусти его, пройди установку на «Экране», потом нажми **«Найти установленные»**: в списке появятся ярлыки из меню «Пуск».
- **.msi** ставится через `msiexec` и дальше работает так же, как .exe.
- **.deb** ставится автоматически, ярлык добавляется сам. Программа должна быть под **amd64** (x86-64), то есть обычная версия «для Linux».
- **.AppImage** запускается сразу.
- **Не запускается?** Открой «⋯» → **«Лог ошибок»**. Если это Electron-программа (большинство ИИ-клиентов), проверь, что в команде есть `--no-sandbox`.

## 4. Ограничения дешёвого сервера (честно)

Сервер за ~100–150 ₽/мес обычно даёт **1 ядро, 1 ГБ памяти, 10–15 ГБ диска, без видеокарты**.

- ✅ Будут работать ИИ-программы, которые **обращаются к облаку**: клиенты ChatGPT/Claude/Gemini/DeepSeek, Cherry Studio, Chatbox, Jan в режиме API, автоматизаторы, парсеры, Telegram-боты с GUI и т.п.
- ⚠️ Electron-программы на 1 ГБ памяти будут медленными. Помогает подкачка, но лучше 2 ГБ RAM.
- ❌ **Локальные нейросети** (Stable Diffusion, LM Studio с моделями, Ollama, ComfyUI, генерация видео) требуют 8–32 ГБ памяти или видеокарту. На таком сервере они не запустятся. Для них нужен сервер с GPU или домашний ПК, и тогда Kaip ставится туда тем же `install.sh`.
- ❌ Игры и 3D: видеокарты нет, всё рисует процессор.

Состояние сервера в реальном времени показывает вкладка «Сервер».

## Обслуживание

```bash
cd Kaip/server
docker compose logs -f desktop      # логи
docker compose restart              # перезапуск
git pull && docker compose up -d --build   # обновление
```

Данные лежат в `server/data/`: `home` — Wine и настройки программ, `kaip` — список программ, deb-пакеты, общая папка.
После обновления или пересборки deb-программы переустанавливаются автоматически.

**Без домена и HTTPS** (только для проверки в локальной сети): в `server/.env` поставь `KAIP_DOMAIN=':80'` и `KAIP_HTTPS='0'`. Пароль тогда передаётся без шифрования, через интернет так не делай.

## Безопасность

- Вход по паролю. После 5 неверных попыток вход блокируется на 5 минут.
- Экран (VNC) не открыт наружу: доступ к нему только через Caddy и только после входа.
- Программы запускаются в контейнере от обычного пользователя. Внутри контейнера у него есть `sudo`, чтобы ставить пакеты, поэтому **не запускай подозрительные .exe**: Wine не антивирус.
- `android/debug.keystore` — общий ключ подписи APK. Он нужен, чтобы новые версии ставились поверх старых. Это не секрет, приложение распространяется только для себя.

## Структура

```
server/
  install.sh              установка на сервер
  docker-compose.yml      контейнеры desktop + caddy
  Caddyfile               HTTPS и защита экрана
  desktop/
    Dockerfile            Debian + Xvnc + noVNC + Openbox + Wine
    supervisord.conf      запуск служб
    launcher/app.py       панель (Flask): программы, установка, файлы, процессы
    launcher/static/      интерфейс панели
android/                  приложение (WebView, без сторонних библиотек)
.github/workflows/        сборка APK на GitHub
```
